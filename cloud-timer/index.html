    One-time iPhone setup

    This lets the "I vaped" button start a real Clock timer, so your phone alerts you even when this page is closed.

    1. Open the Shortcuts app and tap +.
    2. Rename the shortcut to Cloud Timer (exactly).
    3. Add the action Get Numbers from Input. Leave its input as Shortcut Input.
    4. Add the action Start Timer. Tap the time, choose the Numbers variable, and set the unit to minutes.
    5. Tap Done. Then press Test below. Your Clock app should start a 1-minute timer.
    Test A (1-minute timer) Test B (1-minute timer)

    Try both. Whichever one stays in Cloud Timer instead of jumping to the Shortcuts app becomes the one the app uses.
